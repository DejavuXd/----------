# Motion map — «Сила аргумента»

Реализация: Web Animations API + IntersectionObserver, без новых зависимостей.

| Секция | Запуск | Движение |
| --- | --- | --- |
| Hero | Первое появление в viewport | Проявление существующего акцента; три строки заголовка через маску; вертикальное раскрытие портрета; описание и CTA. Последний эффект завершается примерно через 1450 мс. |
| Принципы | Первое пересечение 12% каждого элемента | Текст и карточки: opacity и translateY 20px, задержка второго элемента ряда 110 мс. Hover: тонкая акцентная граница без сдвига содержимого. |
| Фотопереход | Первое пересечение 12% | Маска из центра к краям и scale 1.04 → 1 за 1000 мс, затем изображение остаётся статичным. |
| Практики | Кнопка, клавиатура, свайп | Декодирование нового фото; затухание старого контента 180 мс; обновление номера; горизонтальная маска фото; заголовок, описание и пункты с задержками. Высота заранее зарезервирована. Повторные нажатия обновляют целевой индекс и не запускают конфликтующие переходы. |
| Обо мне | Первое пересечение 12% | Вертикальная маска фото, построчная цитата, последовательное описание. Сведения о квалификации статичны. |
| Консультация | Hover/focus/реальная отправка | Переход цвета кнопки и границы 220 мс, стрелка на 3px; акцент поля без изменения размеров. Используется существующая серверная логика, ложного успеха нет. |
| Footer | Первое пересечение 12% каждой группы | Появление групп с задержками; плавное подчёркивание ссылок. |

Общий easing: cubic-bezier(.22, 1, .36, 1). На ширинах до 800 px смещение 12px и stagger 70 мс. На узких экранах цитата проявляется единым блоком, чтобы сохранить естественные переносы.

Скрывающих исходных CSS-стилей нет: без JavaScript текст и изображения доступны. При prefers-reduced-motion анимации не запускаются; изменение настройки отменяет уже запущенные анимации. Клавиатурный фокус также отменяет скрывающую анимацию своего контейнера. Новые постоянные декоративные объекты не добавлялись; герой использует существующий акцент вместо дополнительной линии.

## Проверка

- Сборка Vite проходит.
- Три автоматических проверки: отсутствие запуска при reduced motion; отмена выполняющейся анимации при смене предпочтения без rejected promise; безопасное отсутствие Animation API.
- В браузере просмотрены первый экран, промежуточная и конечная фазы перехода слайдера, раскрытие большой фотографии, мобильный слайдер.
- Быстрые повторные нажатия дошли до ожидаемого четвёртого слайда; после перехода opacity контейнера возвращается к 1.
- Проверены ширины 320, 375, 480, 768, 1024, 1200, 1440, 1920: горизонтального переполнения не обнаружено.
- Ошибок в журнале браузера не обнаружено.

Полевая оценка Core Web Vitals, тест на реальном сенсорном устройстве и визуальная эмуляция reduced motion в браузере не проводились. Reduced motion проверен автоматическими тестами логики и CSS. Отправка заявок по-прежнему отложена по просьбе пользователя.
