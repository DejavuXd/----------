# Версия 1920 px — 5 ноября 2026

## Реализация

- Максимальная ширина страницы увеличена до 1920 px. Между 1200 и 1920 размеры масштабируются через rem и fluid root size, без transform: scale. Мобильные правила сохранены.
- Inter Tight Regular используется для основного текста; Neue Montreal Regular — для меток и номера слайда, с Inter Tight в fallback. Оба WOFF2 из архива подключены локально. Назначение семейств выбрано по визуальному сопоставлению: свойства слоёв Figma без входа недоступны.
- SVG-логотип из архива установлен в шапке; для тёмного подвала создан вариант с цветом фона макета.
- Портрет «Обо мне», переход с Фемидой и четыре фотографии практик заменены материалами из архива. Главный портрет остаётся чистым изображением из PDF: архивный Frame 48095585 содержит встроенные подписи, которые дублировали бы HTML-текст.
- Четыре слайда перенесены со скриншотов: уголовная, гражданская практика, помощь бизнесу, консультации и документы. Работают кнопки, циклическое переключение и клавиши Left/Right; добавлены touch-жесты без автопрокрутки и объявления для screen reader.
- Высота области слайдов резервируется по самому высокому содержимому на текущей ширине, чтобы последующие секции не сдвигались при переключении.

## Проверка

- Production-сборка Vite успешно завершена после финальных изменений.
- Встроенный браузер: проверены 1920, 1440, 1200, 1024, 768, 480, 375, 320 px. Горизонтального переполнения нет.
- Все четыре слайда проверены на 1920, 1200, 768, 375, 320 px; длинные тексты не выходят за viewport.
- Кнопки проходят цикл 1 → 2 → 3 → 4 → 1, обратная кнопка и клавиши проверены. Высота секции при 1920 одинакова у всех четырёх слайдов: около 1046 px в проверенном браузере.
- Проверены открытие и Escape мобильного меню. Ошибок в журнале браузера не обнаружено.
- Просмотрены screenshot первого экрана и полной страницы на 1920, а также мобильный блок практик на 320. Новые скриншоты показаны в браузерных результатах; файлы qa/screenshots относятся к предыдущей версии.

## Ограничения

Ссылка Figma открывается для визуального просмотра, но интерфейс требует вход для инспекции свойств. Размеры адаптации 1920 и назначение шрифтов не выдаются за подтверждённые свойства Figma; pixel-perfect не заявляется. Изображения практик в архиве имеют разрешение 221 × 294, поэтому на большом экране могут выглядеть мягче, чем фотографии высокого разрешения. Touch-жест реализован, но на реальном сенсорном устройстве не проверялся.
