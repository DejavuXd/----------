# Елена Архипова

Самостоятельный сайт: HTML5, CSS3, Vanilla JavaScript ES Modules, Vite. Фотографии извлечены из предоставленного PDF, без генерации или замены лиц.

## Запуск

```sh
npm install
npm run dev
npm run build
npm run preview
```

Готовые статические файлы сборки находятся в `dist/`. Версия адаптирована до 1920 px; подключены локальные шрифты Inter Tight и Neue Montreal, SVG-логотип и четыре направления практики. Актуальная проверка описана в `qa/1920-status.md`. Для публикации нужен статический хостинг и отдельный серверный маршрут для формы. Отправка заявок отложена по просьбе пользователя.

## Что требует завершения

- Сверить точное назначение двух предоставленных шрифтов и размеры со свойствами Figma, когда будет доступна инспекция. Оба семейства уже подключены.
- При наличии заменить фотографии практик 221 × 294 версиями высокого разрешения. Все четыре направления уже реализованы; автопрокрутки нет.
- Утверждённые политика конфиденциальности и согласие: разместить документы, заменить текстовые обозначения ссылками, затем установить `VITE_CONTACT_LEGAL_READY=true`.
- Подтверждение контактов, профессиональных сведений и текста, перенесённых из PDF; ссылки социальных кнопок. Социальные кнопки без адресов не добавлены; исходный SVG-логотип подключён.
- Домен для canonical, материалы Open Graph.

## Контракт формы

Скопировать `.env.example` в `.env`, указать `VITE_CONTACT_ENDPOINT=/api/contact` после создания действующего обработчика на том же origin. `VITE_` переменные публичны: в них нельзя хранить ключи или пароли.

Запрос: POST JSON `{ name, phone, email, consent: true }`. Успех: HTTP 2xx и JSON `{ "ok": true }`, возвращённые после подтверждённого приёма заявки сервером. Клиент не считает обычную HTML-страницу или произвольный HTTP 200 успешной отправкой. Предусмотрен таймаут 15 секунд; при неопределённом результате нет автоматического повтора, чтобы не дублировать заявку.

Сервер должен повторно проверять данные, ограничивать частоту запросов, защищаться от спама и отправлять уведомление выбранным пользователем способом. Не журналировать содержимое заявки. Способ доставки и сервер пока не согласованы. Без endpoint и утверждённых юридических документов форма не отправляет данные и предлагает связаться по телефону. Данные не сохраняются в localStorage и не пишутся в консоль.

## Проверка

`qa/browser-check.mjs` использует установленный отдельно Playwright и Edge, не добавляя их в зависимости сайта. Перед проверкой запустить Vite на порту 5173:

```sh
node qa/browser-check.mjs /absolute/path/to/playwright/index.mjs
```

Проверяются восемь контрольных ширин, отсутствие горизонтального переполнения, загрузка изображений, мобильная навигация, ошибки формы, отсутствие отправки без настроек, reduced motion и ошибки консоли. Скриншоты сохраняются в `qa/screenshots`. Проверка реальной доставки требует настроенного серверного обработчика. Визуальную точность типографики можно оценить только после подключения согласованного шрифта.
